# APE-06-Arreglos-y-Listas

¡Bienvenido a este repositorio! Aquí encontrarás una colección de **10 ejercicios prácticos** desarrollados para dominar el uso de estructuras de datos lineales como `Arrays`, `ArrayList` y `LinkedList`. 

El objetivo principal de esta guía es comprender el almacenamiento, manipulación y optimización de colecciones de datos en memoria.

---

## 🚀 Contenido del Proyecto

Los ejercicios están organizados por categorías según la estructura de datos utilizada:

### 🔹 ArrayList (Nivel Básico)
* **Ejercicio 1 – ArrayList I:** Creación y almacenamiento de 5 nombres de estudiantes.
* **Ejercicio 2 – ArrayList I:** Gestión de un listado de 6 notas académicas.
* **Ejercicio 3 – ArrayList I:** Registro de productos en un catálogo y desarrollo de un motor de búsquedas funcional.

### 🔸 ArrayList (Nivel Avanzado & CRUD)
* **Ejercicio 4 – ArrayList II:** Creación de un menú interactivo con operaciones **CRUD** (Crear, Leer, Actualizar, Eliminar).
* **Ejercicio 5 – ArrayList II:** Registro e interacción simultánea de nombres de estudiantes junto con sus respectivas notas.
* **Ejercicio 6 – ArrayList II:** Diseño y simulación de un sistema de control de inventario dinámico.

### ⚖️ Comparativas: Arreglos vs. ArrayList
* **Ejercicio 7 – Arreglo vs ArrayList:** Análisis teórico y práctico sobre las diferencias estructurales entre un arreglo fijo y un `ArrayList`.
* **Ejercicio 8 – Arreglo vs ArrayList:** Comparativa de rendimiento y sintaxis al momento de realizar inserciones masivas de datos.

### 🟢 LinkedList (Estructuras Enlazadas)
* **Ejercicio 9 – LinkedList:** Simulación y manipulación de un sistema de asignación de turnos.
* **Ejercicio 10 – LinkedList:** Modelado de una fila de atención al cliente (comportamiento FIFO / Cola).

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java / C++
* **IDE:** VS Code
* **Estructuras:** `Array` nativo, `ArrayList`, `LinkedList`
